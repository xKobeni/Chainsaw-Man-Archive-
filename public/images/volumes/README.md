# Volume cover assets

No authorized cover images are present. The volume gallery and featured panel use a neutral raster paper placeholder with an explicit “COVER PENDING” label. It is not a fabricated manga illustration.

To supply licensed covers, add `01.webp` through `24.webp` (or PNG/JPG/AVIF equivalents) here and set the matching `cover` field in `src/data/volumes.ts` to `/images/volumes/01.webp`, etc. Use portrait 2:3 images; 600×900 pixels or larger is recommended. Missing or failed image URLs fall back to the local placeholder.

Only volume ranges in `src/data/volumes.ts` with verified evidence are shown. Details that have not been verified remain unset.
