# Volume cover assets

The volume gallery and featured panel use the supplied `csm_volume_1.jpg` through `csm_volume_24.jpg` artwork, mapped in `src/data/volumes.ts`.

If a cover is missing or fails to load, the local raster paper placeholder remains available. Replacement covers should keep the current portrait proportions (approximately 0.635 width to height) so their edges remain visible.

Only volume ranges in `src/data/volumes.ts` with verified evidence are shown. Details that have not been verified remain unset.
